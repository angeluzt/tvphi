# Sonidos / efectos

Aquí irán los efectos de sonido (pasos, puertas, ambiente, impactos…).

Nombra cada archivo de forma clara (ej. `pasos-madera.mp3`, `lluvia-suave.wav`).
Opcional: un `catalogo.md` con la lista y una línea de descripción por sonido.

La IA usará estos sonidos como referencia para ambientar mejor la obra.
