# Música de fondo

Aquí irán las canciones (~50) que la IA podrá elegir para ambientar las historias.

Pon cada archivo de audio en esta carpeta. Añade un archivo de descripción
(por ejemplo `catalogo.md` o un `.txt` por canción) indicando para qué sirve
cada pieza: tono, emoción, cuándo usarla.

La IA usará este catálogo como referencia; aún no elige automáticamente.
